# JobProof v0.4：知乎驱动的微项目选题

## 目标

在完成能力确认和 JD 分析后，用户可以按需从知乎真实讨论中选择微项目主题。JobProof 读取知乎搜索结果的标题、短摘要、作者、权威等级和互动量，生成 3 个可执行选题；用户确认后，来源链接会随计划保存。

## 用户流程

```text
完成四步能力确认 → 分析目标 JD → 选择能力缺口
→ 点击“从知乎找 3 个选题” → 选择一个候选
→ 生成 7/14 天微项目 → 在计划页查看知乎来源
```

知乎检索是按需操作，不会在打开页面时自动调用，也不会批量抓取或建立知乎内容镜像。

## API

```text
POST /api/zhihu/project-context
```

请求示例：

```json
{
  "jdTitle": "产品运营实习生",
  "targetCompetency": "interview",
  "targetName": "用户访谈",
  "theme": "校园服务"
}
```

服务端使用 `ZHIHU_ACCESS_SECRET` 调用知乎站内搜索接口：

```text
GET https://developer.zhihu.com/api/v1/content/zhihu_search
```

请求只携带能力关键词、JD 标题和可选主题，不把完整 JD 发送给知乎搜索。未配置 Access Secret 时返回 `configured: false`，页面继续支持自定义主题。

## 来源保存

选中的来源作为 `Plan.sources` 保存到本地计划：

- `sourceId`
- `title`
- `url`
- `excerpt`
- `authorName`
- `authorityLevel`
- `engagement`
- `retrievedAt`

只保存必要的短摘要和来源信息，不保存知乎全文。后续接入云端计划 Repository 时，可将同一结构写入 `plans.metadata` 或独立的 `project_sources` 表。

## 边界与安全

- 只使用知乎官方搜索 API，不进行网页抓取。
- Access Secret 仅在服务端环境变量中使用，不进入浏览器、日志、URL 或 Git。
- 搜索结果是选题参考，不代表 JobProof 或用户本人观点。
- 候选卡片保留知乎原始链接和作者信息，用户可回到原文核验。
- 接口限流或额度不足时停止请求，用户仍可手动输入主题。

## 当前未开启

- 使用用户个人收藏和创作历史自动生成主题；
- JD、计划、证据和来源的云端同步；
- 自动读取知乎全文或批量建立知识库。
